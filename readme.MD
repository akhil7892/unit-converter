# 🔄 Unit Converter Tool

A simple and user-friendly **Unit Converter Tool built with Python and Tkinter**.
This project allows users to quickly convert values between different units using a graphical user interface (GUI).

## 📌 Features

* 📏 **Length Conversion**

  * Meter
  * Kilometer
  * Centimeter
  * Millimeter
  * Mile
  * Yard
  * Foot
  * Inch

* ⚖️ **Weight Conversion**

  * Kilogram
  * Gram
  * Milligram
  * Pound
  * Ounce

* 🌡️ **Temperature Conversion**

  * Celsius
  * Fahrenheit
  * Kelvin

* 💧 **Volume Conversion**

  * Liter
  * Milliliter
  * Gallon
  * Quart
  * Pint
  * Cup

* ⏱️ **Time Conversion**

  * Second
  * Minute
  * Hour
  * Day
  * Week

* 🖥️ Simple Tkinter GUI

* 🔄 Easy unit selection

* 🧹 Clear button

* ⚠️ Input validation and error messages

* 🚀 Lightweight and easy to use

## 🛠️ Technologies Used

```bash

```

## 🖥️ How to Use

1. Launch the application.
2. Select a conversion category.
3. Enter the value you want to convert.
4. Select the **From** unit.
5. Select the **To** unit.
6. Click **CONVERT**.
7. The converted value will appear on the screen.

### Example

```text
Category: Length
Value: 10
From: Meter
To: Foot

Result:
10 Meter = 32.8084 Foot
```
